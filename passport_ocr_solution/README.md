# Постобработка OCR паспорта РФ

Офлайн-решение на стандартной библиотеке Python. Обрабатывает по одной JSONL-строке на документ, формирует `accept` только после проверок качества, форматов, дат, срока действия паспорта и согласованности MRZ. Необработанные данные включены в `data/`.

## Запуск

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Для сверки обучающей выборки:

```bash
python postprocess.py data/train_predictions.jsonl train_answers.jsonl
python evaluate.py train_answers.jsonl data/train_labels.jsonl
```

В коде заданы правила актуальности паспорта на 01.10.2026. Решение сознательно консервативно: `mobile_v2` не принимается автоматически, так как его уверенности в этих данных насыщены значением 1.0 даже при неверном распознавании. Пороговые значения описаны в `report.md`.

## Файлы

- `postprocess.py` — решение.
- `answers.jsonl` — ответы для тестовых 2000 документов.
- `report.md` — краткий отчёт и оценка результата.
- `data/` — входные данные задания и обучающая разметка.
- `reference/subdivisions.csv` — справочник из задания (с исходной атрибуцией в `reference/SOURCE.txt`).
- `evaluate.py` — предоставленный оценщик.
